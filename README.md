# IPL Analytics Dashboard

## Overview
Interactive IPL Analytics Dashboard built using Power BI, Python, Pandas, and DAX.

This project analyzes:
- Team performance
- Player statistics
- Batting and bowling impact
- Match insights
- Dynamic rankings

---

## Tools Used
- Power BI
- Python
- Pandas
- DAX
- Data Modeling

---

## Dashboard Pages
1. Executive Overview
2. Team Performance Analysis
3. Player Analysis
